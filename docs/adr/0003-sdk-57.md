# ADR 0003 — SDK 57

## Context

Live docs (18 Aug 2026): current stable is Expo SDK 57 (RN 0.86.2 as of `expo@57.0.9+`). Hermes V1 memory regression is fixed in 57.0.9. This scaffold landed on `expo@57.0.14`.

## Decision

Pin the project to SDK 57 via `default@sdk-57`. Do not use Store Expo Go (SDK 54) as the daily driver.

## Consequences

Need `eas go` or a dev client / Simulator for iOS.

## Revisit-when

SDK 58 ships.
